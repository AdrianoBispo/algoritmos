# Algoritmos de Grafos

Grafo é uma estrutura de dados não linear, assim como a [estrutura de árvore](https://www.geeksforgeeks.org/dsa/tree-data-structure/). Um grafo é composto por um conjunto de vértices (****V****) e um conjunto de arestas (****E****). Os vértices são conectados entre si por meio das arestas.

-   A limitação da árvore é que ela só pode representar dados hierárquicos. Em situações em que nós ou vértices estão conectados de forma arbitrária, usamos grafos.
-   Exemplos de uso da estrutura de grafos incluem redes sociais, redes de computadores, redes de localização em GPS e muitos outros cenários em que diferentes nós ou vértices se conectam sem hierarquia ou restrição estrutural.

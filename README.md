Este repositório reúne explicações e exemplos de algoritmos organizados por tema. A ideia é servir como um índice rápido para estudo, consulta e navegação entre as pastas do projeto.

## Estrutura do Repositório

| Tópico | Descrição |
| --- | --- |
| [Algoritmos Matemáticos](alg01_math-algorithms/README.md) | Conceitos como divisibilidade, MDC e MMC, úteis para análise e otimização de problemas. |
| [Busca](alg02_searching/README.md) | Técnicas para localizar elementos em coleções de dados, incluindo buscas lineares, binárias, em grafo e por hash. |
| [Padrões de Busca](alg03_patterns-searching/README.md) | Algoritmos para localizar ocorrências de padrões em textos maiores. |
| [Ordenação](alg04_sorting/README.md) | Estratégias para organizar elementos em uma ordem específica, como crescente, decrescente ou por critérios personalizados. |
| [Sliding Window](alg05_window-sliding/README.md) | Técnica para resolver problemas de subarrays e subsequências com janelas deslizantes. |
| [Soma de Prefixo](alg06_prefix-sum/README.md) | Pré-processamento para consultas rápidas de soma em intervalos. |
| [Recursão](alg07_recursao/README.md) | Abordagem em que a solução de um problema depende de versões menores dele mesmo. |
| [Backtracking](alg08_backtracking/README.md) | Exploração sistemática de possibilidades com retrocesso quando uma escolha não leva à solução. |
| [Dividir e Conquistar](alg09_divide-and-conquer/README.md) | Estratégia de dividir um problema em partes menores, resolver cada parte e combinar os resultados. |
| [Algoritmos Gananciosos](alg10_greedy/README.md) | Algoritmos que tomam a melhor decisão local em cada etapa na expectativa de uma boa solução global. |
| [Programação Dinâmica](alg11_dynamic-programming/README.md) | Técnica para evitar recomputações ao armazenar resultados de subproblemas. |
| [Branch and Bound](alg12_branch-and-bound/README.md) | Métodos de otimização que podam partes da busca com base em limites. |
| [Algoritmos Geométricos](alg13_geometric/README.md) | Algoritmos para problemas com pontos, linhas, polígonos e outras formas geométricas. |
| [Algoritmos Randomizados](alg14_randomized/README.md) | Técnicas que usam aleatoriedade para simplificar ou acelerar soluções. |
| [Algoritmos Bitwise](alg15_bitwise-algorithms/README.md) | Operações e truques com bits para resolver problemas de forma eficiente. |

# 📚 Algoritmos e Estruturas de Dados

![Mapa Mental - Análise de Algoritmos](./infograficos/Mapa%20Mental%20-%20Análise%20e%20Estrutura%20de%20Algoritmos.png)

Bem-vindo(a) ao repositório de **Algoritmos!** 🚀

Este projeto é um espaço dedicado ao estudo, implementação e documentação de diversos algoritmos fundamentais da ciência da computação. O principal objetivo é criar um acervo prático, direto e que sirva como um excelente material de consulta, seja para aprimorar suas habilidades em programação, preparar-se para entrevistas técnicas ou utilizar a base como referência de aprendizado contínuo.

> Para melhor proveito, recomendo você acessar também o meu diretório [Estrutura de Dados](https://github.com/AdrianoBispo/estrutura-de-dados) pois ele serve de complemento e até de conhecimento prévio para os conceitos apresentados nos algoritmos apresentados nesse repositório.

---

## 📂 Estrutura do Projeto

Nossa organização reflete uma jornada progressiva e estruturada para quem quer praticar algoritmos. Cada tema possui uma pasta dedicada, contendo explicações da teoria (frequentemente representadas em arquivos `README.md`) e resoluções práticas espalhadas por níveis de dificuldade:

```text
algoritmos/
├── 📁 algXX_tema/
│   ├── 📄 README.md (Explicação teórica do assunto)
│   └── 📁 exercicios/
│       ├── 📄 README.md (Índice dos exercícios)
│       ├── 📁 ex01_facil/ (Algoritmos e desafios de nível Fácil)
│       ├── 📁 ex02_medio/ (Algoritmos e desafios de nível Médio)
│       └── 📁 ex03_dificil/ (Algoritmos e desafios de nível Difícil)
├── 📁 infograficos/ (Esquemas, fluxogramas e mapas mentais)
└── 📄 README.md (Este arquivo)
```

Essa divisão padrão (Fácil, Médio, Difícil) facilita a escolha dos desafios mais adequados para o momento de cada estudante ou desenvolvedor, assegurando aprendizado incremental.

## 🗂️ Tópicos Abordados

Abaixo, encontram-se os roteiros categorizados que compõem este repositório:

| Tópico | Pasta Principal | Descrição |
| --- | --- | --- |
| **Algoritmos Matemáticos** | [`alg01_math-algorithms`](alg01_math-algorithms/README.md) | Conceitos vitais como divisibilidade, MMC, MDC, úteis para análise e otimização de problemas analíticos. |
| **Busca (Searching)** | [`alg02_searching`](alg02_searching/README.md) | Técnicas (busca linear, busca binária, etc.) para isolar e localizar elementos de dados com maior performance. |
| **Ordenação (Sorting)** | [`alg03_sorting`](alg03_sorting/README.md) | Estratégias (Quick, Merge, Bubble Sort, etc.) para organizar coleções segundo critérios de interesse. |
| **Dois Ponteiros (Two Pointers)** | [`alg04_two-pointers`](alg04_two-pointers/README.md) | Otimizações baseadas no movimento iterativo de dois apontadores em coleções, comuns em desafios técnicos. |
| **Janela Deslizante (Sliding Window)**| [`alg05_sliding-window`](alg05_sliding-window/README.md) | Como lidar com intervalos que se processam contínua e deslizantemente em arrays e strings. |
| **Soma de Prefixo (Prefix Sum)** | [`alg06_prefix-sum`](alg06_prefix-sum/README.md) | Estratégias de pré-processamento para consultas instantâneas (O(1)) a soma em intervalos. |
| **Busca de Padrões** | [`alg07_patterns-searching`](alg07_patterns-searching/README.md) | Busca inteligente que avança em pedaços (como KMP, Rabin-Karp) para achar padrões em textos completos. |
| **Recursão** | [`alg08_recursao`](alg08_recursao/README.md) | Problemas sofisticados cuja solução passa pela evocação sequencial de subprocessos análogos. |
| **Backtracking** | [`alg09_backtracking`](alg09_backtracking/README.md) | Busca minuciosa por exaustão que utiliza o fluxo de "tentativa e erro" controlados para chegar a resultados válidos. |
| **Algoritmos Gananciosos** | [`alg10_greedy-algorithms`](alg10_greedy-algorithms/README.md) | Escolhas locais instantaneamente promissoras que em teoria buscam ótimo global (como Fractional Knapsack). |
| **Programação Dinâmica (DP)** | [`alg11_dynamic-programming`](alg11_dynamic-programming/README.md) | Superando recursões ineficientes via técnica de guardar resultados (memoização/tabulação) de subproblemas repetidos. |
| **Algoritmos Geométricos** | [`alg12_geometric-algorithms`](alg12_geometric-algorithms/README.md) | Interseções cruciais e problemas espaciais de pontos, polígonos, raios e linhas. |
| **Algoritmos Randomizados**| [`alg13_randomized-algorithms`](alg13_randomized-algorithms/README.md) | Utilização controlada de casualidade como geradores randômicos para contornar gargalos ou simplificar o pior-caso. |
| **Manipulação de Bits** | [`alg14_bitwise-algorithms`](alg14_bitwise-algorithms/README.md) | Matemática binária: máscaras, flags, shifts aplicados para resolver quebra-cabeças com extrema velocidade e baixo uso real de memória. |

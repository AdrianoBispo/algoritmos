### O que é e por que aprender?

A técnica de Prefix Sum é um padrão de algoritmo focado em pré-processar um array (ou matriz) para permitir que consultas de soma em intervalos (range sum queries) sejam respondidas instantaneamente. Em termos de complexidade, ela transforma operações que normalmente levariam tempo linear **O(N)** — iterar repetidamente sobre o mesmo intervalo — em operações de tempo constante **O(1)**. Essa técnica é a base para o processamento de imagens, análise de séries temporais de dados financeiros, estatísticas de jogos e otimização de bancos de dados.
